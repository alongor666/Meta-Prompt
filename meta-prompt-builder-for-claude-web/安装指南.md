
## 🚀 安装步骤（5分钟）

### Step 1: 登录Claude.ai

访问 https://claude.ai 并登录

### Step 2: 创建新项目

1. 点击左侧边栏 **"Projects"**
2. 点击 **"+ New Project"**
3. 项目名称: `Meta Prompt Builder`
4. （可选）添加描述: `智能Prompt生成器 - 渐进式披露设计`

### Step 3: 设置Custom Instructions

1. 在项目页面，点击 **"Settings"** 或齿轮图标
2. 找到 **"Custom Instructions"** 区域
3. 打开 `instructions.md` 文件
4. **复制全部内容**粘贴到 Custom Instructions
5. 点击 **"Save"**

### Step 4: 上传Knowledge Files

1. 在项目页面，点击 **"Add content"** 或 **"📎"** 图标
2. 选择 **"Upload files"**
3. **一次性上传** `knowledge-files/` 目录下的所有6个文件：
   - template_business_deep.md
   - template_quick_eval.md
   - template_learning.md
   - template_technical.md
   - template_risk.md
   - usage_guide.md
4. 等待上传完成（显示✓）

### Step 5: 验证安装

在项目对话框中输入：

```
使用Meta Prompt Builder: 我需要评估一个AI客服系统，预算200万
```

如果Claude开始按照工作流程执行（任务识别→用户画像→提问），说明安装成功！

## 💡 设计理念

### 为什么这样设计？

**Instructions（精简）**:
- ✅ 只包含核心工作流程和逻辑
- ✅ 明确何时调用哪个文件
- ✅ 减少token消耗
- ✅ 提高响应速度

**Knowledge Files（按需加载）**:
- ✅ 详细的模板内容
- ✅ Claude按需读取
- ✅ 渐进式披露
- ✅ 用户不会被信息淹没

### vs 传统做法的对比

| 维度 | 传统做法 | 渐进式披露 |
|------|---------|-----------|
| Instructions大小 | 14KB（包含所有模板） | 6.5KB（仅核心逻辑） |
| Token消耗 | 每次加载全部 | 按需加载 |
| 响应速度 | 慢（解析大量内容） | 快（精简指令） |
| 灵活性 | 低（固定内容） | 高（动态组合） |
| 维护性 | 差（修改一处影响全部） | 好（模块化） |

## 🔧 常见问题

### Q1: Claude没有按照Meta Prompt Builder执行？

**A**: 检查：
1. Custom Instructions是否正确设置（完整复制了instructions.md）
2. 触发词是否正确（"使用Meta Prompt Builder: ..."）
3. Knowledge Files是否全部上传（6个文件）

### Q2: Claude说找不到模板文件？

**A**: 确认：
1. 6个Knowledge Files都已上传
2. 文件名是否正确（template_business_deep.md等）
3. 尝试重新上传文件

### Q3: 生成的Prompt太简单/太复杂？

**A**:
- 太简单：提供更多背景信息（预算、时限、角色）
- 太复杂：明确说"简化版本"或"快速评估"

### Q4: 想修改某个模板怎么办？

**A**:
1. 下载对应的template文件
2. 在本地修改
3. 重新上传替换原文件
4. Claude会自动使用新版本

## 🎓 进阶技巧

### 技巧1: 自定义模板

1. 复制一个现有模板（如template_technical.md）
2. 修改为你的特定场景（如"医疗设备评估"）
3. 上传为新的Knowledge File（template_medical.md）
4. 在Instructions.md中添加匹配规则：
   ```
   ELSE IF 任务类型="医疗设备评估"
      → 📗 调用 template_medical.md
   ```
5. 重新上传Instructions.md

### 技巧2: 组合使用

要求Claude同时使用多个模板：
```
使用Meta Prompt Builder: 评估技术方案（技术评估模板） + 识别风险（风险模板）
```

### 技巧3: 迭代优化

```
你: 使用Meta Prompt Builder: [需求]
Claude: [生成Prompt v1]
你: 增加数据安全部分的权重
Claude: [读取模板 → 调整 → 生成Prompt v2]
你: 简化为快速版
Claude: [切换template_quick_eval.md → 生成Prompt v3]
```

## 🔄 更新与维护

### 如何更新模板？

1. 本地修改模板文件
2. 在Claude.ai项目中删除旧文件
3. 上传新版本
4. 无需修改Instructions（除非更改文件名）

### 如何添加新模板？

1. 创建新模板文件（参考现有格式）
2. 上传到Knowledge Files
3. 在Instructions.md中添加匹配规则
4. 重新上传Instructions.md

### 版本控制建议

- 本地保留模板文件副本
- 使用Git管理（可选）
- 记录每次修改（在usage_guide.md末尾添加changelog）
