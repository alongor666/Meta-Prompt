## 使用技巧

### 技巧1: 越具体越好

❌ **不好**: "分析这个方案"
✅ **更好**: "评估是否采购"
⭐ **最佳**: "我是CTO，2周内决定是否投200万采购这个系统"

### 技巧2: 说明约束条件

❌ **不好**: "分析方案"
✅ **更好**: "快速分析，今天汇报"
⭐ **最佳**: "3小时内完成，1页摘要，重点关注ROI和合规"

### 技巧3: 明确受众

❌ **不好**: "做个分析"
✅ **更好**: "做详细分析"
⭐ **最佳**: "给董事会的报告，需要数据支撑"

### 技巧4: 允许迭代

```
你: 使用Meta Prompt Builder: 评估XX方案
Claude: [生成Prompt]
你: 太复杂了，简化版本，只保留核心框架
Claude: [生成简化版]
```

## 5种模板适用场景

### 📘 商业决策深度分析
- **适用**: 重大商业决策、B2B采购、投资评估
- **深度**: ★★★★★ (60-90分钟)
- **输出**: 执行摘要 + 详细报告 + 决策清单
- **示例**: 评估500万风控系统采购、是否投资某项目

### 📗 快速评估
- **适用**: 紧急决策、小额采购、初步筛选
- **深度**: ★★☆☆☆ (10-20分钟)
- **输出**: 一句话结论 + TOP3优势/风险 + 立即行动
- **示例**: 今天内决定是否采购SaaS工具、快速筛选供应商

### 📙 学习知识萃取
- **适用**: 论文解读、行业研究、技能学习
- **深度**: ★★★★☆ (40-60分钟)
- **输出**: 知识地图 + 概念卡片 + 学习路径
- **示例**: 学习网约车保险风控、理解区块链技术

### 📕 技术可行性评估
- **适用**: 技术选型、架构评审、POC设计
- **深度**: ★★★★☆ (45-60分钟)
- **输出**: 技术评分卡 + 风险矩阵 + POC计划
- **示例**: 评估是否采用微服务架构、选择前端框架

### 📔 风险识别
- **适用**: 项目风险评估、合规审查、安全排查
- **深度**: ★★★☆☆ (30-45分钟)
- **输出**: 风险矩阵 + 缓解方案 + 应急预案
- **示例**: 识别项目上线风险、合规审查

## 适用场景判断

### ✅ 什么时候用Meta Prompt Builder?

1. **任务复杂度高**
   - 多维度分析需求
   - 决策影响重大

2. **重复性任务**
   - 每月分析10份方案
   - 希望标准化流程

3. **用户不确定**
   - 新手不知道怎么问
   - 跨领域任务

4. **质量要求高**
   - 向董事会汇报
   - 需要可复现流程

### ❌ 什么时候不用?

1. 简单查询（"Python语法是..."）
2. 创意发散（头脑风暴）
3. 即时响应（聊天对话）
4. 专家明确知道要什么

## 核心原理

Meta Prompt Builder基于5大原则:

1. **Context Precision（上下文精确性）**
   - 精确捕获用户角色、目标、约束

2. **Constraint-Driven（约束驱动）**
   - 用约束条件定义输出边界

3. **Comparative Reasoning（对比推理）**
   - 提供多种对比维度（横向/纵向/基准）

4. **Layered Output（分层输出）**
   - 分层设计输出（摘要→详细→清单）

5. **Gap Highlighting（盲区提示）**
   - 明确标注需验证和需补充的信息
