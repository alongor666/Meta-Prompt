# Meta Prompt Builder - 智能Prompt生成器

根据用户的模糊需求，自动生成结构化、高质量的分析Prompt。适用于复杂决策、深度分析、学习研究等场景。

## 核心能力

- 🎯 **智能任务识别**: 自动识别任务类型（决策/技术/学习/风险）
- 🧠 **用户画像推理**: 推断用户专业水平、时间预算、输出偏好
- 📋 **模板智能匹配**: 从5大模板库中选择最优组合
- 🔄 **渐进式引导**: 最少3个问题获取关键信息
- ✅ **质量保证**: 自动检查生成的Prompt完整性

## 使用场景

**适用** ✅:
- 商业方案评估（B2B采购、投资决策、合作评估）
- 技术选型分析（架构设计、工具选型、可行性评估）
- 学习知识萃取（论文解读、行业研究、技能学习）
- 风险识别排查（项目风险、合规风险、技术风险）
- 重复性分析任务（需要标准化流程）

**不适用** ❌:
- 简单事实查询（"今天天气如何"）
- 创意发散类任务（头脑风暴、自由探索）
- 即时聊天对话（不需要结构化分析）
- 用户已是专家且明确知道要用什么框架

## 工作流程

```
用户输入模糊需求
    ↓
Step 1: 任务类型识别
    ↓
Step 2: 用户画像推理
    ↓
Step 3: 信息缺口检测
    ↓
Step 4: 模板智能匹配
    ↓
Step 5: 渐进式引导（如需补充信息）
    ↓
Step 6: 生成定制化Prompt
    ↓
Step 7: 质量检查 + 用户确认
    ↓
输出可直接使用的Prompt
```

## 执行指令

当用户调用此技能时，请按以下步骤执行：

### Step 1: 捕获并识别任务

```markdown
【自动分析用户输入】

识别任务类型:
□ 决策评估类（评估、选择、采购、投资）
□ 技术分析类（架构、选型、可行性、POC）
□ 学习研究类（理解、学习、研究、深入）
□ 风险识别类（风险、合规、安全、排查）
□ 其他

提取关键词:
- 动词: [评估/分析/学习/...]
- 主体: [方案/系统/技术/...]
- 约束: [预算/时间/团队/...]
```

### Step 2: 推理用户画像

```markdown
【基于输入内容推断】

专业水平:
- 🟢 新手: 使用通用术语，无专业背景
- 🟡 中级: 使用领域术语，但不深入
- 🔴 专家: 使用专业术语+技术细节

时间预算:
- ⚡ 紧急: 包含"快速"、"立刻"、"今天"
- 🕐 常规: 未明确时限，推测1-2周
- 🕰️ 充裕: 包含"深入"、"全面"、"详细"

输出偏好:
- 🎯 结论导向: "告诉我答案"、"推荐"
- 🔬 过程导向: "帮我理解"、"分析"
- 🚀 行动导向: "告诉我怎么做"、"下一步"

角色识别:
- 决策者: CEO/总监/负责人
- 执行者: 工程师/分析师/专员
- 学习者: 研究人员/学生/新人
```

### Step 3: 信息缺口检测

```markdown
【检查必要信息】

核心5项检查:
□ 角色/身份（我是谁？从什么视角分析？）
□ 目标/目的（要达成什么？决策标准是什么？）
□ 约束/边界（预算？时限？团队能力？）
□ 对比/基准（与什么比较？有无替代方案？）
□ 输出/格式（给谁看？什么形式？多长？）

缺失程度判定:
- 缺失 ≥ 4项 → 🔴 进入完整引导模式
- 缺失 2-3项 → 🟡 进入简化引导模式
- 缺失 ≤ 1项 → 🟢 直接生成（使用合理默认值）
```

### Step 4: 模板智能匹配

```markdown
【从模板库选择最优模板】

匹配逻辑:

IF 任务类型 = "决策评估" AND (专家 OR 充裕时间) AND 预算>100万
   → 推荐: 📘 商业决策深度分析模板

ELSE IF 任务类型 = "决策评估" AND (紧急 OR 预算<50万)
   → 推荐: 📗 快速评估模板

ELSE IF 任务类型 = "学习研究"
   → 推荐: 📙 学习知识萃取模板

ELSE IF 任务类型 = "技术分析"
   → 推荐: 📕 技术可行性评估模板

ELSE IF 任务类型 = "风险识别" OR 关键词包含["风险","合规","安全"]
   → 推荐: 📔 风险识别模板

ELSE
   → 推荐: 📗 快速评估模板（通用）

模板组合策略:
- 可以推荐主模板(1个) + 补充模板(1-2个)
- 例如: 商业决策模板 + 风险识别补充
```

### Step 5: 渐进式引导

```markdown
【根据信息缺失程度决定引导策略】

🔴 完整引导模式（缺失≥4项）:

"我将帮你生成一个定制化的分析Prompt。为了确保质量，需要先了解几个关键信息：

**问题1: 你的角色和目标是什么？**
- 选项A: 我是决策者，需要评估是否采购/合作
- 选项B: 我是执行者，需要深入分析技术细节
- 选项C: 我是学习者，想要理解某个领域/概念
- 选项D: 其他（请描述）

**问题2: 你的时间和预算约束？**
- 选项A: 紧急（3天内决策，预算<50万）
- 选项B: 常规（1-2周决策，预算50-500万）
- 选项C: 充裕（1个月以上，预算>500万或长期投入）
- 选项D: 不确定/灵活

**问题3: 你希望得到什么样的输出？**
- 选项A: 简洁结论（1页执行摘要，给领导看）
- 选项B: 详细分析（15页报告，内部讨论）
- 选项C: 行动清单（具体执行步骤）
- 选项D: 以上都要（分层输出）"

---

🟡 简化引导模式（缺失2-3项）:

"基于你的描述，我推荐使用【{模板名称}】。

在生成Prompt前，请补充1-2个关键信息：

**{最关键的缺失项}**:
{提供3个选项或开放式提问}

（可选）**{次要缺失项}**:
如不提供，我将使用合理默认值"

---

🟢 直接生成模式（缺失≤1项）:

"我将使用【{模板名称}】为你生成定制化Prompt。

检测到的信息:
✓ 角色: {推断的角色}
✓ 目标: {推断的目标}
✓ 约束: {推断的约束或默认值}

{如有1项缺失，提示}:
⚠️ 未提供{缺失项}，将使用默认设定: {默认值}
如需调整，请告知。

是否确认生成？"
```

### Step 6: 生成定制化Prompt

```markdown
【填充对应模板】

1. 读取选定的模板文件:
   - references/template_business_deep.md
   - references/template_quick_eval.md
   - references/template_learning.md
   - references/template_technical.md
   - references/template_risk.md

2. 填充变量:
   - {role} = 用户角色
   - {goal} = 核心目标
   - {constraints} = 约束条件
   - {budget} = 预算
   - {timeline} = 时限
   - {output_format} = 输出格式
   - {custom_focus} = 特别关注点
   - ... (根据模板定义)

3. 动态调整:
   - 如果是新手 → 简化框架说明，增加示例
   - 如果是专家 → 保留专业术语，减少解释
   - 如果紧急 → 简化流程，聚焦核心
   - 如果充裕 → 增加深度分析选项
```

□ 清晰的约束条件（预算/时间/必要条件）
□ 指定的分析框架（至少2个）
□ 结构化的输出要求（分层/分节）
□ 质量验证机制（自检清单）

检查不通过 → 自动补充缺失项

【输出格式】

"✅ Prompt生成完成！

---

## 📋 生成的定制化Prompt

{完整的Prompt内容}

---

## 📊 使用说明

**预期效果:**
- 分析深度: {深度级别}
- 预计耗时: {预估时间}

## 最佳实践

### 1. 明确你的核心需求

❌ 不好: "帮我分析一下"
✅ 更好: "我需要评估是否采购这个系统"
⭐ 最佳: "我是CTO，需要在2周内决定是否投入200万采购这个系统，请帮我生成全面的评估Prompt"

### 2. 提供关键约束

❌ 不好: "分析这个方案"
✅ 更好: "快速分析这个方案，我今天要汇报"
⭐ 最佳: "3小时内完成分析，输出1页执行摘要，重点关注ROI和数据合规风险"

### 3. 说明受众

❌ 不好: "做个分析"
✅ 更好: "做个详细分析"
⭐ 最佳: "生成一份给董事会的分析报告，需要数据支撑和风险量化"

### 4. 允许迭代

不要期望一次生成完美Prompt，可以:
- 先生成MVP版本
- 试用后提出调整
- 逐步优化到最佳

## 性能优化

### Token优化

为了降低Token消耗:
