## 风险量化分析

### 风险矩阵
```
            影响程度
           轻微  中等  严重
概率 高      🟡   🔴   🔴
    中      🟢   🟡   🔴
    低      🟢   🟢   🟡
```

### 风险分布
- 🔴 高风险: {high_risk_count}个（必须缓解）
- 🟡 中风险: {medium_risk_count}个（需要监控）
- 🟢 低风险: {low_risk_count}个（可接受）

### 风险期望值
```
总风险期望损失 = Σ(概率 × 影响)
= {risk_1_prob} × {risk_1_impact} + ...
= {total_expected_loss}万

vs 缓解成本 = {mitigation_cost}万

决策:
- 如果缓解成本 < 期望损失 → 建议缓解
- 如果缓解成本 > 期望损失 → 可接受风险
```

## 决策建议

基于风险评估，建议:

**Go决策** - 如果:
- ✅ 所有🔴高风险都有可行的缓解方案
- ✅ 风险期望损失 < 预期收益的30%
- ✅ 关键风险可控（概率<10% OR 影响可承受）

**Wait决策** - 如果:
- ⏸️ 存在🔴高风险但缓解方案不明确
- ⏸️ 需要更多信息才能判断
- ⏸️ 外部环境不确定性太高

**No-Go决策** - 如果:
- ❌ 存在不可接受的风险（如合规红线）
- ❌ 风险期望损失 > 预期收益
- ❌ 关键风险无法缓解
