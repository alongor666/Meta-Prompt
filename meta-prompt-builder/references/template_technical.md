风险评级标准:
- 🔴 高风险: 概率高且影响大 → 必须有缓解方案才能推进
- 🟡 中风险: 概率或影响之一较高 → 需要监控和应对计划
- 🟢 低风险: 概率低且影响小 → 可接受
