# Meta Prompt Builder - 使用指南

## 🎯 这是什么？

Meta Prompt Builder 是一个智能Prompt生成器，能够根据你的模糊需求，自动生成结构化、高质量的分析Prompt。

**核心价值**: 让普通用户也能像专家一样提问。

---

## 💡 为什么需要它？

### 传统方式的问题
❌ "帮我分析这个方案" → AI给出泛泛的分析
❌ 不知道该问什么 → 错过关键信息
❌ 每次都要重新思考Prompt结构 → 浪费时间

### 使用Meta Prompt Builder
✅ 自动识别你的需求类型
✅ 引导你补充关键信息
✅ 生成定制化的高质量Prompt
✅ 确保分析的完整性和深度

---

## 🚀 快速开始

### 基础用法
```
/meta-prompt-builder 我需要评估一个网约车保险方案
```

系统会自动:
1. 识别这是"商业决策"任务
2. 询问你几个关键问题
3. 生成定制化的分析Prompt
4. 你确认后直接使用

---

## 📚 5个核心模板

### 1. 📘 商业决策深度分析
- **适用**: 重大商业决策、B2B采购、投资评估
- **深度**: ★★★★★
- **耗时**: 60-90分钟
- **输出**: 执行摘要 + 详细报告 + 决策清单

**示例**:
```
/meta-prompt-builder 评估是否采购智车睿控的风控系统，预算500万
```

---

### 2. 📗 快速评估
- **适用**: 紧急决策、小额采购、初步筛选
- **深度**: ★★☆☆☆
- **耗时**: 10-20分钟
- **输出**: 一句话结论 + TOP3优势/风险 + 立即行动

**示例**:
```
/meta-prompt-builder 快速评估这个SaaS工具，今天要决定
```

---

### 3. 📙 学习知识萃取
- **适用**: 论文解读、行业研究、技能学习
- **深度**: ★★★★☆
- **耗时**: 40-60分钟
- **输出**: 知识地图 + 概念卡片 + 学习路径

**示例**:
```
/meta-prompt-builder 我想深入学习网约车保险风控，我是保险新人
```

---

### 4. 📕 技术可行性评估
- **适用**: 技术选型、架构评审、POC设计
- **深度**: ★★★★☆
- **耗时**: 45-60分钟
- **输出**: 技术评分卡 + 风险矩阵 + POC计划

**示例**:
```
/meta-prompt-builder 评估是否采用微服务架构，团队10人
```

---

### 5. 📔 风险识别
- **适用**: 项目风险评估、合规审查、安全排查
- **深度**: ★★★☆☆
- **耗时**: 30-45分钟
- **输出**: 风险矩阵 + 缓解方案 + 应急预案

**示例**:
```
/meta-prompt-builder 识别这个项目的所有风险，我们风险厌恶型
```

## 🎓 使用技巧

### 技巧1: 越具体越好
❌ 不好: "分析这个"
✅ 更好: "评估是否采购"
⭐ 最佳: "我是CTO，2周内决定是否投200万采购这个系统"

### 技巧2: 说明约束条件
❌ 不好: "分析方案"
✅ 更好: "快速分析，今天汇报"
⭐ 最佳: "3小时内完成，1页摘要，重点关注ROI和合规"

### 技巧3: 明确受众
❌ 不好: "做个分析"
✅ 更好: "做详细分析"
⭐ 最佳: "给董事会的报告，需要数据支撑"

### 技巧4: 允许迭代
- 先生成MVP版本
- 试用后提出调整
- 逐步优化

## 🎯 适用场景判断

### ✅ 什么时候用Meta Prompt Builder?

1. **任务复杂度高**
   - 多维度分析需求
   - 决策影响重大

2. **重复性任务**
   - 每月分析10份方案
   - 希望标准化流程

3. **用户不确定**
   - 新手不知道怎么问
   - 跨领域任务

4. **质量要求高**
   - 向董事会汇报
   - 需要可复现流程

### ❌ 什么时候不用?

1. 简单查询 ("Python语法是...")
2. 创意发散 (头脑风暴)
3. 即时响应 (聊天对话)
4. 专家明确知道要什么

## 🔧 故障排查

### 问题1: 生成的Prompt太复杂
**解决**: 告诉系统"简化版本，只保留核心框架"

### 问题2: 生成的Prompt不符合需求
**解决**:
1. 提供更多背景信息
2. 明确说明期望输出
3. 参考示例调整

### 问题3: 不知道选哪个模板
**解决**: 描述你的任务，系统会自动推荐
