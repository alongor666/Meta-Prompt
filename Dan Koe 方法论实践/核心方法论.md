 🎯 核心理念（1 句话）

  把 AI 当作"可编程的数字员工"，而非"随机答案的老虎机"

---

  🧠 三大核心认知转变

1. 从使用者 → 编排者

- ❌ 错误：问 AI"帮我写..."然后用默认输出
- ✅ 正确：设计精确指令，控制输出质量

2. 从零散任务 → 系统构建

- ❌ 错误：每次重新输入提示词
- ✅ 正确：建立可复用的 Prompt 库

3. 从浅层提示 → 深度编程

- ❌ 错误："帮我写一篇关于 XX 的文章"（20 字）
- ✅ 正确：500-2000 字的详细指令（角色+流程+示例+约束）

---

  📐 核心方法：5 部分 Prompt 结构

1. 【系统】= 角色定义
   "你是一位资深的 [专业领域] 专家，擅长..."
2. 【上下文】= 背景信息
   "我需要...[具体情况/目标/约束条件]"
3. 【指令】= 执行步骤
   "请按照以下步骤：
   Step 1: ...
   Step 2: ...
   Step 3: ..."
4. 【示例】= 参考模板（可选）
   "参考这个例子：[具体案例]"
5. 【约束】= 输出格式
   "输出格式：[Markdown/表格/列表]
   字数：[范围]
   语气：[专业/轻松/...]"

---

  🔄 核心工作流：四步循环

  ┌─────────────────────────────────────┐
  │ 1. 提炼知识                          │
  │    将你的技能/流程文字化              │
  │    (500-2000字的详细描述)            │
  └──────────┬──────────────────────────┘
             │
             ↓
  ┌─────────────────────────────────────┐
  │ 2. 转化为 Prompt                     │
  │    使用 5 部分结构                    │
  │    越详细 = 输出越好                  │
  └──────────┬──────────────────────────┘
             │
             ↓
  ┌─────────────────────────────────────┐
  │ 3. 实战使用                          │
  │    真实任务中测试                     │
  │    记录问题和不满意之处                │
  └──────────┬──────────────────────────┘
             │
             ↓
  ┌─────────────────────────────────────┐
  │ 4. 迭代优化                          │
  │    根据反馈修改 Prompt                │
  │    版本管理（v1.0 → v1.1 → v2.0）    │
  └──────────┬──────────────────────────┘
             │
             └──────→ 回到步骤 3（持续循环）

  🎯 四种知识提炼方法

| 方法           | 适用场景       | 示例                                      |
| -------------- | -------------- | ----------------------------------------- |
| 自身知识法     | 你已精通某技能 | 你会写文案 → 把写作流程文字化            |
| 标准化任务法   | 通用常见任务   | 客户画像、SWOT 分析 → 让 AI 生成标准流程 |
| 专家知识提炼法 | 想学习新领域   | 找相关 PDF/视频 → 让 AI 提炼教学指南     |
| 反向工程法     | 有优秀案例     | 收集好文章 → 让 AI 分析写作套路          |

  💡 关键洞察（3 个悖论）

  悖论 1：更长的 Prompt = 更自然的输出

- 短提示（20 字）→ AI 味重、通用化
- 长提示（500 字）→ 个性化、像你写的

  悖论 2：花时间建 Prompt = 节省未来时间

- 初期投入：2 小时创建 1 个 Prompt
- 长期回报：使用 50 次，每次节省 30 分钟 = 节省 25 小时

  悖论 3：限制越多 = 创意越好

- 无约束 → AI 输出宽泛模糊
- 强约束（格式+风格+字数）→ AI 在框架内深度创新

---

  🔑 实战应用的三个层次

  Level 1：工具层（大多数人停留在这里）

- 偶尔问 AI 问题
- 复制粘贴输出
- 每次重新输入提示

  Level 2：系统层（Dan Koe 的目标）

- 建立 15-20 个核心 Prompt 库
- 覆盖工作中 80% 的重复任务
- 持续优化和版本迭代

  Level 3：生态层（高级玩法）

- 多个 Prompt 串联成工作流
- AI 成为"思维伙伴"而非执行工具
- 创造独特的 AI 使用方法论

---

  🎓 三个核心 Prompt 类型

1. 执行型 Prompt（做事）

- 写内容、分析数据、生成方案
- 示例：内容大纲生成器、需求拆解大师

2. 思考型 Prompt（想事）

- Thought Partner（思维伙伴）
- Strategic Advisor（战略顾问）
- 通过提问引导你产生洞察

3. 学习型 Prompt（学事）

- 知识提炼器、概念解释器
- 将复杂信息转化为可操作知识

---

  ⚡ 立即可用的核心公式

  高质量 AI 输出 =
      清晰的意图传递
      × 丰富的上下文约束
      × 持续的迭代优化

  其中：

- 意图传递 = 你的思维流程清晰度
- 上下文约束 = 你提供的具体信息量
- 迭代优化 = 你的反馈循环质量
