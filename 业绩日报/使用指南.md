# 保险业务业绩分析系统 - 使用指南

## 🚀 快速开始

### 1. 运行演示
```bash
cd 业绩日报
python3 simple_demo.py
```

### 2. 查看报告
打开 `业绩日报/templates/daily_report.html` 文件即可查看A-G七个维度的完整分析报告。

## 📊 A-G七个维度详解

### 🅰️ A. 签单保费总额分析
- **总保费**：分析期间内的总签单保费金额
- **日均保费**：平均每日签单保费
- **单日最高**：记录最高单日保费
- **总签单数**：总的保单笔数统计

### 🏆 B. 业绩统计分析
- **最佳业务员**：保费最高的业务员
- **最佳机构**：业绩最好的三级机构
- **业绩集中度**：TOP人员贡献占比分析

### 📊 C. 产品组合分析
- **交叉销售率**：交叉销售业务占比
- **主要险种**：保费贡献最大的险种
- **产品状况**：产品组合的均衡性评估

### 👥 D. 客户细分分析
- **续保率**：续保业务占总业务比例
- **新车占比**：新购车辆业务比例
- **客户结构**：个人/企业/团体客户分布

### 📱 E. 渠道来源分析
- **最佳渠道**：业绩最好的渠道来源
- **渠道多样性**：不同渠道的数量统计
- **数字化程度**：线上vs线下渠道占比

### 📈 F. 保费趋势分析
- **趋势方向**：上升/下降/平稳判断
- **周增长率**：与上周对比的增长率
- **稳定性**：业务增长的稳定性评估

### ⚡ G. 特殊业务分析
- **新能源车占比**：新能源车辆业务比例
- **过户车占比**：过户车辆业务比例
- **市场机会**：基于特殊业务的市场机会识别

## 📋 数据要求

### 必需字段
| 字段名 | 数据类型 | 说明 |
|---------|---------|------|
| 日期 | 日期 | 签单日期 |
| 业务员 | 文本 | 负责业务员姓名 |
| 三级机构 | 文本 | 所属分支机构 |
| 签单保费 | 数值 | 保单保费金额 |
| 险别 | 文本 | 保险类型 |
| 交叉销售 | 文本 | 是否交叉销售 |
| 客户类别 | 文本 | 客户类型 |
| 车辆类型 | 文本 | 新车/旧车 |
| 是否续保 | 文本 | 是否续保客户 |
| 终端来源 | 文本 | 业务来源渠道 |
| 是否新能源 | 文本 | 是否新能源车 |
| 是否过户车 | 文本 | 是否过户车辆 |

### 数据格式建议
- **日期格式**：YYYY-MM-DD 或 MM/DD/YYYY
- **金额格式**：数值类型，无需货币符号
- **文本字段**：使用统一的枚举值
- **数据完整性**：避免空值和异常值

## 📞 技术支持

### 常见问题
1. **数据文件格式错误**
   - 确保Excel文件包含所有必需字段
   - 检查日期格式是否正确
   - 验证金额字段为数值类型

2. **分析结果不准确**
   - 检查数据是否有重复或异常值
   - 确认分析时间段设置正确
   - 验证业务规则配置

3. **图表显示异常**
   - 更新浏览器到最新版本
   - 检查网络连接是否正常
   - 清除浏览器缓存后重试
