# 保险业务业绩日报分析系统

## 概述
本系统专门用于保险业务数据的深度分析，涵盖七个核心维度的业绩统计与可视化展示。

## 核心分析维度

### A. 签单保费总额分析
- 每日/每周/每月签单保费统计
- 同比/环比增长分析
- 目标达成率追踪

### B. 业绩统计分析
- **业务员个人业绩排行**
- **三级机构业绩对比**
- 团队业绩贡献度分析

### C. 产品组合分析
- **险别组合占比分析**
- **交叉销售效果评估**
- 产品策略优化建议

### D. 客户细分分析
- **客户类别分布统计**
- **新旧车业务占比**
- **续保率跟踪分析**

### E. 渠道来源分析
- **终端来源效果统计**
- 渠道转化率对比
- 获客成本效益分析

### F. 保费趋势分析
- **签单保费时间趋势**
- 季节性波动识别
- 预测模型建立

### G. 特殊业务分析
- **新能源车业务统计**
- **过户车业务分析**
- 市场机会识别

## 使用说明
1. 准备Excel数据文件，包含必需的字段
2. 运行 `insurance_analyzer.py` 进行分析
3. 查看生成的HTML报告和图表
4. 根据分析结果制定业务策略
